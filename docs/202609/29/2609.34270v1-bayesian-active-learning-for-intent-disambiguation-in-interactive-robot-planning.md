## 摘要
交互式机器人规划要求机器人从往往存在歧义、不完整或欠指定的自然语言指令中推断并执行人类意图。尽管大语言模型（LLM）为澄清提供了强大的接口，但依赖生成模型驱动多轮对话可能会引入系统性失败。我们提出一个贝叶斯框架，将澄清视为在具体化的信号时序逻辑（STL）任务规范上的主动学习问题。我们的方法使用LLM初始化候选形式化规范，并将有信息量的对比转化为自然语言澄清问题，同时贝叶斯优化维护对用户意图的不确定性估计，并选择能最大化信息增益的查询。收敛后，推断出的STL规范被传递给形式化规划器，以合成可验证的机器人轨迹。在四个仿真和真实世界任务领域中，我们的方法通常比LLM基线获得更高的任务满足度，并且需要更少的澄清轮次，同时帮助较小模型缩小与较大推理模型之间的性能差距。

## Abstract
Interactive robot planning requires robots to infer and execute human intentions from natural language instructions that are often ambiguous, incomplete, or underspecified. Although large language models (LLMs) provide a powerful interface for clarification, relying on the generative model to drive an multi-turn conversation can introduce systematic failures. We propose a Bayesian framework that treats clarification as an active learning problem over grounded Signal Temporal Logic (STL) task specifications. Our method uses LLMs to initialize candidate formal specifications and translate informative contrasts into natural-language clarification questions, while Bayesian optimization maintains uncertainty estimation over user intent and selects queries that maximize information gain. After convergence, the inferred STL specification is passed to a formal planner to synthesize a verifiable robot trajectory. Across four simulated and real-world task domains, our approach generally achieves higher task satisfaction and requires fewer clarification rounds than LLM baselines, while helping smaller models close the performance gap against larger reasoning models.

## 1. 核心问题与整体含义

- **研究动机**：交互式机器人规划需要将人类自然语言指令转化为可验证、可执行的计划。然而真实场景中用户的指令往往**歧义、不完整、欠指定**——例如"去 Tom 的办公室"缺少物理接地（办公室在哪）、常识约束（经过人时减速）和用户偏好（哪个 Tom、何时到达）。
- **背景痛点**：LLM 虽提供了强大的语言接口，但让生成模型主导多轮澄清会带来**系统性失败**：
  - 多轮对话中的上下文丢失（context loss）；
  - 对用户的谄媚（sycophancy）与过度自信（over-confidence）；
  - 早期错误假设被后续轮次不断放大。
- **现有方法的缺口**：
  - 语言接地形式化规划（LLM+P、NL2TL、AutoTAMP 等）大多**隐含假设初始指令足够完整**，只关注"指令→形式化"的翻译，忽略了前置的交互澄清问题；
  - 现有澄清方法（KnowNo、Masked IRL 等）依赖 LLM 记忆或置信度，缺乏理论化的不确定性建模；
  - 偏好学习方法（贝叶斯偏好学习、IRL、从演示学习）学到的对象常是**奖励函数或特征抽象**，与下游规划器可验证的形式化任务满足之间关系**间接**，形成"学到什么"与"能验证什么"之间的鸿沟。
- **整体含义**：论文主张把澄清（clarification）从"LLM 驱动的对话"重新表述为**形式化假设空间上的贝叶斯主动信息收集问题**，让推断出的意图直接落到可被形式化规划器验证的信号时序逻辑（STL）规范上。

## 2. 方法论

### 2.1 核心思想
- 将用户潜在意图表示为**接地的 STL 任务规范** ϕ ∈ Φ_G（Φ_G 为接地命题上的有效规范集合），定义效用函数 U*(ϕ) 衡量候选规范与用户真实意图的匹配度，推断目标为 ϕ* = argmax_{ϕ∈Φ_G} U*(ϕ)。
- **LLM 只作语义支持模块**：初始化候选规范、把"对比"翻译成自然语言问题、解析用户回答并赋效用估计。
- **概率模型负责严格的不确定性估计与查询选择**：贝叶斯优化在高斯过程（GP）后验上选择最大化信息增益的查询。
- **形式化规划器负责验证与执行**：收敛后把推断规范交给 STL 约束规划器合成可验证轨迹。

### 2.2 关键技术细节
- **STL 规范空间**：由接地谓词作为原子公式，经布尔算子与时序算子（F[a,b] 最终、G[a,b] 始终、U[a,b] 直到）递归组合而成。例如 F[0,30] p_goal 表示 30 秒内到达目标，G[0,H] ¬p_unsafe 表示全程避障。STL 还提供鲁棒性分数 ρ_ϕ(ξ)，ρ_ϕ(ξ) ≥ 0 表示满足，可直接对接轨迹优化器。该递归结构使规范**模块化、可解释**，每个子公式对应一个语义约束。
- **隐效用模型**：由于 Φ_G 离散且组合爆炸，用 **Grammar VAE** 把 STL 公式嵌入连续隐空间 Z：编码器 E_ψ(ϕ)=z，解码器 D_ψ(z)=ϕ（受上下文无关文法约束，保证解码出语法合法公式）。隐效用定义为 u*(z) = U*(D_ψ(z))，用**高斯过程**维护后验：
  - u(z)|D_t ~ N(μ_t(z), σ²_t(z))，其中 μ_t 估计匹配度，σ²_t 表示不确定性。
  - LLM 基于初始指令与任务上下文提出候选集 C_0 及先验效用估计，引导初始搜索朝向语义合理的区域。
- **主动澄清查询选择**（式 3）：每轮选两个候选对比：
  - **当前最优**：z_best_t = argmax_{z∈Z_Ct} μ_t(z)；
  - **有信息量的替代**：z_query_t = argmax_{z∈Z_t} α_t(z)，其中 α_t(z) = I(y; u | z, D_t) + λ μ_t(z)，即"期望信息增益 + 效用奖励"。
  - **关键点**：查询池 Z_t = Z_Ct ∪ S_t，S_t 是直接在隐空间采样的点。由于解码器把任意隐点映射为合法公式，系统可以提出 **LLM 从未生成过的新颖挑战者规范**，而不仅是重排 LLM 候选。
- **对话流程**：解码得到 ϕ_best_t 与 ϕ_query_t，LLM 把二者差异翻译成自然语言问题 Q_t（针对最能区分两者的属性，如时间窗口）；用户自由回答 A_t 后，LLM 给两个规范赋直接效用估计，作为 u* 的含噪观测加入反馈集；LLM 再基于对话历史重新生成候选集 C_{t+1}（保留被查询的挑战者），重拟合效用模型。
- **停止、规范选择与规划**：每轮把当前估计 ϕ_best_t 交给形式化规划器求解
  - ξ_t = argmin_{ξ∈Ξ_feasible} C(ξ) s.t. ξ |= ϕ_best_t；
  - 当通用停止测试 STOP(ϕ_best_t, ξ_t, D_t) 成功或查询预算 B 耗尽时终止，返回 ϕ̂ = ϕ_best_t 与 ξ* = ξ_t。STOP 保持通用（如用户批准轨迹即成功），实现**意图推断与轨迹优化的解耦**。
- **算法 1** 给出完整流程：LLM 初始化 → 拟合效用模型 → 选最优并规划 → 停止判断 → 选查询 → LLM 提问 → 用户回答 → LLM 更新 → 循环。

## 3. 实验设计

### 3.1 场景与 Benchmark
- **仿真域 1（Franka Panda）**：7 自由度桌面操作任务，每场景 14 个物体（含语义标签、颜色、形状、度量位置），需到达指定彩色物体并避开红色球等不安全物体。上下文含末端执行器位姿、工作空间边界、物体属性与位置、可采纳谓词；接地原子命题如 reach(orange cube)、avoid(red ball)。规划用梯度式轨迹优化器最大化 STL 鲁棒性。
- **仿真域 2（City）**：基于 Lang2LTL 的 OpenStreetMap 2D 城市级导航，每图 40 个地标，因名称/类别/街道描述相似而产生接地歧义。建模为有限语义迁移系统 M = (S, A, T, s_0, L)，用 LTL 规范，翻译为 Büchi 自动机后与 M 合成在积系统上求解。
- **真实部署**：School（学术室内）与 Factory（工业）两个物理站点，Unitree Go2 四足机器人执行推断规范；用 XGrids PortalCam 扫描构建含物体标签、3D 包围盒、可通行区域的度量-语义表示；推断规范交给 MILP 规划器生成航点，Go2 用 MPC 跟踪并以 CBF-QP 安全滤波器做局部避障。
- **测试任务生成**：四类时序逻辑模板族——单目标、多目标、顺序（全序）、偏序（仅前驱约束）；每个规范含 2–12 个接地对象/区域（目标、障碍、时序依赖），时间区间随机采样；所有规范经对应规划器过滤以保证可行。
- **歧义生成**：对每个真值规范隐藏接地或时序信息，覆盖三类歧义——**指称歧义**（多个对象/地标属性相似）、**常识/安全歧义**（省略相关约束）、**偏好歧义**（目标/障碍/优先级未指定）。假设**低主动性用户**：初始指令省略信息，每次回答只澄清一个方面，形成信息瓶颈，使问题选择变得关键。
