## 摘要
对象缩放是一种基础的空间操作，能够支持XR环境中的复杂且高效的任务。本文研究了使用注视和手部交互的XR单手缩放技术。我们提出了UniScale，这是一组替代标准双手捏合的单手方案，允许用户在缩放对象的同时保持另一只手可进行并发的空间操作。我们设计了五种基于物理隐喻的不同映射策略，探索了深度、角度、微手势和手指距离输入的单手控制变化。然后，我们将这些技术与标准的双手基线（即用户通过双手捏合手势调整双手间距）进行比较。在一项用户研究中，我们在有离合器（clutching）和无离合器条件下评估了它们在3D对象缩放任务中的有效性。结果表明，双手缩放依赖离合器来实现稳定控制，而单手技术则在无离合器条件下表现出色，显著减少了物理手部移动。根据结果，我们得出了在XR中开发高效3D多模态交互的有价值的设计启示。

## Abstract
Object scaling serves as a fundamental spatial manipulation that enables complex and productive tasks in XR environments. This paper investigates unimanual scaling techniques for XR using gaze and hand interactions. We propose UniScale, a set of unimanual alternatives to the standard bimanual pinch, allowing users to scale objects while preserving hand availability for concurrent spatial manipulations. We design five distinct mapping strategies based on physical metaphors, exploring unimanual control that varies depth, angle, micro-gestures, and finger-distance input. We then compare these techniques against a standard bimanual baseline, in which users adjust the inter-hand distance via a bimanual pinch gesture. In a user study, we evaluate their effectiveness in a 3D object scaling task under both clutching and clutching-free conditions. The results indicate that while bimanual scaling relies on clutching for stable control, unimanual techniques excel in clutching-free conditions, significantly reducing physical hand movement. From the results, we derive valuable design implications for developing efficient 3D multimodal interactions in XR.

## 论文总结

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **背景**：现代XR头显的Gaze+Pinch交互模型已成为目标选择的主流方式，但现有研究多聚焦于基础的选择机制，对缩放、旋转、平移（RST）等空间操控的研究不足。缩放是XR中基础而核心的操作，但缺少与Gaze+Pinch无缝衔接的缩放设计。
- **核心问题（研究动机）**：目前产业界普遍采用双手对称捏合手势（如Apple Vision Pro等）来实现缩放，两手之间的距离与对象尺寸呈1:1同构映射。该方案虽直观，却存在结构性缺陷：
  - **双手占用**：缩放过程占用双手，不能同时进行其他平移、旋转等；
  - **物理疲劳**：大范围缩放需要反复clutch（离合器式重新定位），且双臂长期悬空造成“无尾熊手臂”式疲劳。
- **论文目标**：探讨在Gaze+Pinch范式下的单手缩放方案，让非惯用手执行缩放、惯用手可用于并发空间操作，从而提升XR中空间操控的连续性与无缝性。

### 2. 论文提出的方法论：核心思想、关键技术细节

- **总体设计**：提出UniScale，一套基于间接输入的单身缩放技术。交互流程分两步：注视指示目标物体并捏合激活缩放模式；之后通过不同单手手势控制缩放。整体基于Guiard的非对称双手运动链模型，将缩放控制分配给非惯用手，平移等精细操作分配给惯用手。

- **五种映射技术**：
  - **uniDepth**：非惯用手捏合激活；手沿z轴（深度方向）前后移动控制缩放。映射公式：`S_new = S_initial × r`，其中`r = 1 − Δz`，`Δz = z_current − z_initial`。前推缩小、后拉放大，与“拉近即放大”的感知可供性（affordance）对齐。
  - **uniAngle**：使用非惯用手捏合激活，根据手在垂直方向（y轴）的位移对应角度变化控制缩放。`r = 1 − Δθ`，其控制类似于滑块隐喻。
  - **uniMicro**：以拇指微手势（拇指MCP-指尖向量投影到参考平面的角度变化）控制缩放，使用拇指轻触激活模式。`r = 1 − Δθ`。优点是手部移动量极小，缺点是高依赖手部追踪稳定性。
  - **uniSemi**：单手半捏合，以食指-拇指间的捏合距离同构映射到对象比例，实现1:1等距映射。激活通过手腕旋转（掌心朝向阈值0.75开启、0.65关闭，带滞后防止状态抖动）。
  - **biSemi**：非对称双手方案，惯用手选目标并激活（使用拇指-中指捏合以区别于标准拇指-食指捏合），非惯用手用半捏合指距控制缩放。

- **Clutching机制设计**：
  - **Clutching条件**：用户可在操作边界释放再重新激活，以继续缩放；
  - **Clutching-free条件**：激活手势保持期间连续缩放，缩放速度根据手的位移大小分三档（慢/中/快），并配有固定在手上的进度条实时显示缩放方向与幅度。

- **实现环境**：Meta Quest Pro HMD + Unity 3D（2022.3.39f1），使用1€滤波器（fcmin=1.0 Hz，β=0.07）去除追踪噪声，并采用注视稳定性算法（100ms时间窗内角偏差超过5°即锁定），并进行了视觉反馈指示（手指上的色点、物体的轮廓颜色等）。

### 3. 实验设计：场景、benchmark与对比方法

- **实验场景**：VR环境中的3D对象精确缩放任务（符合既有研究范式）：初始1 m立方体置于4.5 m前方，需匹配四种目标边长：0.333 m、0.577 m、1.732 m、3 m（对数间隔，消除放大/缩小难度偏差）；尺寸精度需与目标相±0.05 m内持续500 ms才算完成。此外还设有**后续平移阶段**：缩放完成后，将立方体平移至左侧或右侧4.5 m处的目标球。
- **对象距离**在4.5 m，确保间接交互场景的有效性（超出臂长）。
- **对比方法**：
  - 基线方法为**biDistance**：双手捏合，对象尺寸与双手间距成正比。这是商业系统中最常见的缩放技术。
  - 对比对象为UniScale的五个技术：uniDepth、uniAngle、uniMicro、uniSemi、biSemi。
  - 此外，每种技术都在**clutching**与**clutching-free**两种条件下评测。
- **被试**：20名（M=25.05，SD=2.70；男性15人、女性5人；全部右撇子；部分戴眼镜或隐形眼镜）来自当地大学。

### 6. 论文的主要结论与发现

- **任务完成时间**：uniDepth（M=2.568 s）与uniAngle（M=2.606 s）最快，与基线biDistance（M=2.781 s）无显著差异，但均显著快于uniMicro、uniSemi、biSemi。交互效应显著：uniDepth、uniAngle、uniMicro在clutching-free模式更快，biDistance与biSemi在clutching模式更快，uniSemi无显著差异。
- **初始获取时间**：主要效应显示uniAngle与uniDepth显著快于基线；交互效应显示双手技术（biDistance、biSemi）在clutching-free条件下大幅下降，单手速率型技术反而受益于clutching-free。
- **精调时间**：clutching-free（M=.574 s）显著快于clutching（M=1.325 s）。双手技术精调时间最短，但单手技术整体受clutching拖累更严重。uniMicro和uniSemi从clutching模式移除中获益最大。
- **误差率**：biDistance误差率最低（M=3.165%），uniMicro最高（M=5.880%），clutching-free平均误差高于clutching模式。
- **尝试次数**：biDistance最少（M=1.162），uniMicro最多（M=2.098），clutching-free整体尝试次数少于clutching条件。
- **物理手部移动量**：uniMicro（M=.150 m）和biSemi（M=.197 m）最少，uniDepth最大（M=.454 m）。clutching-free显著减少手部移动。
- **主观偏好**：biDistance和uniDepth排名最高（clutching-free条件更佳）；uniAngle中等；biSemi与uniMicro居中；uniSemi排名最低。clutching-free整体偏好更高，其可预测性和易学习性获得用户好评（部分用户仍偏好clutching以获得更强的控制感）。

由此形成的核心观点是：**clutching的有效性取决于映射结构**——同构映射（biSemi、biDistance）适合离散clutching（因为它保留身体姿态的“本体感觉参照”）；速率型/非线性映射（uniDepth、uniAngle、uniMicro）则更适clutching-free连续操作（因它需要累积学习的速度增益）。此外，手势的自然可供性（如拉近/推出=放大/缩小）能提升直观性；低体力消耗可部分弥补精度不足。

### 8. 不足与局限（包括实验覆盖、偏差风险、应用限制）

- **并发多任务的验证缺失**：虽然论文主张“单手能进行多任务”，但实验仅顺序执行缩放和平移，没有真正验证并发执行（如左手缩放、右手同时平移/旋转）。实验设计可能因此有利益倾斜。
