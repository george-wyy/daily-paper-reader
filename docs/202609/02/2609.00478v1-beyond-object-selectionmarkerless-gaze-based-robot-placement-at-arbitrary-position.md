## 摘要
基于注视的辅助操作通常支持物体选择，而任意位置放置需要头显与机器人之间的精确空间对齐。然而，对于基于注视的操作，位姿精度并不一定转化为任务精度：平移和旋转误差共同影响变换后的注视射线，并可能相互补偿。为了从这种面向任务的角度研究跨设备对齐，我们提出了一种无标记交互框架和一个专门的跨设备数据集。我们提出了基于图的参考选择方法来解决机器人参考稀疏的问题。我们进一步在统一协议下开发并基准测试了多种特定任务的对齐流程。具体而言，我们引入了注视-表面交点误差（GSIE），它直接测量注视指定目标的空间误差。实验表明，在传统位姿指标上排名靠前的对齐方法在GSIE上并不总是最优的，这证明了在任务层面评估基于注视的操作的重要性。

## Abstract
Gaze-based assistive manipulation typically supports object selection, while arbitrary-position placement requires accurate spatial alignment between the headset and robot. However, for gaze-based manipulation, pose accuracy does not necessarily translate into task accuracy: translational and rotational errors jointly affect the transformed gaze ray and may compensate for each other. To study cross-device alignment from this task-oriented perspective, we present a markerless interaction framework and a dedicated cross-device dataset. We propose Graph-based Reference Selection to address sparse robot references. We further develop and benchmark multiple task-specific alignment pipelines under a unified protocol. Specifically, we introduce Gaze--Surface Intersection Error (GSIE), which directly measures the spatial error of the gaze-specified target. Experiments show that alignment methods ranked highly by conventional pose metrics are not always optimal in GSIE, demonstrating the importance of evaluating gaze-based manipulation at the task level.

## 一、核心问题与研究动机

本文聚焦基于注视（Gaze）的人机交互在**机器人辅助操作**中的应用，特别是物体放置任务。研究动机可归纳为以下几点：

- 传统基于注视的辅助操作系统，如 FAM-HRI、Gear 等，通常仅支持物体层面的选择（例如通过注视识别目标物体），而不支持机器人将物体放置到用户指定的**任意空间位置**。这是因为需要在头戴式设备（Headset）与机器人之间建立精确的跨设备空间对齐，而这一点在“无标记”（Markerless）的开放场景下尚未被充分研究。

- 现有基于视觉的跨设备对齐方法，如基于基准标记（ArUco/AprilTag），虽能提供高精度位姿估计，但依赖标记的持续可见性，容易受遮挡、运动范围限制等影响，难以支撑自然交互场景。

- 作者进一步指出一个更具挑战性的核心问题：**位姿估计精度并不等同于任务执行精度**。跨设备对齐中的平移误差与旋转误差在传播到三维空间中由注视射线与物体表面交点的位置时，可能相互抵消，也可能相互放大。因此就需要一种面向最终放置效果的任务级评估指标，而非仅考察传统位姿误差。

- 另一个研究缺口是缺乏大规模、带配对观测的专用跨设备数据集，比较机器人视角与头戴式视觉参考之间的结构关联较为困难，特别是设备视角极不相同的情况下。

## 二、论文提出的方法论

### 核心思想
文章提出一套端到端的**无标记跨设备交互框架**，划分为场景采集阶段与基于注视的交互阶段两个环节，并辅以一系列可贡献任务级精度的关键技术。

### 关键技术细节

1. **场景重建与三维对齐**
   - 机器人利用其搭载的RGB-D相机对桌面工作空间进行水平圆弧扫描，采集多视角参考图像与对应深度图；
   - 采用 MapAnything 生成三维场景重建，并通过 Kabsch–Umeyama 对齐和 ICP 融合，得到机器人基座坐标系下的 3D 场景模型，支撑后续物体地图与交点计算。

2. **基于图的参考视图选择（Graph-based Reference Selection）**
   - 由于机器人只在稀疏的多个视角观察场景，而头戴相机视角差异大，特征匹配容易失效。因此需要先选出最“兼容”的机器人参考视图；
   - 作者没有直接使用逐对图像特征匹配或全局外观检索，而是建立一个**物体语义关系图**；
   - 图中节点由物体实例（YOLO26 检测所得）构成，而边则由物体间的**层级相对位置关系（上下、左右）** 编码，并使用角度直方图形式表达局部结构；
   - 同一空间中头戴视图的图结构与每个机器人参考图通过矩阵余弦相似度比较，并用匈牙利算法做全局最优双向匹配；得分最高的机器人图像即作为后续配准的参考图。

3. **几何位姿估计与多种对齐管线**
   - 在选定参考图后，系统分别支持并集成了点级、线级，以及物体级三种对齐策略；
   - **点级配准**使用PnP配合SuperPoint+LightGlue或LoMa等局部特征匹配器；
   - **PnP+Line 扩展**：通过LSD检测线段，结合深度信息做RANSAC三维直线拟合，并结合线特征与点特征进行复合位姿优化从而在纹理弱、但结构强的区域改善估计精度；
   - **物体级精化（Ellipsoid Refinement）**：为每个物体提取最小体积包围椭球（MVEE），并在预测投影与2D图像外接椭圆间通过Wasserstein距离做对象级的位姿优化，从而利用整体的对象尺寸与边界约束。

4. **任务级度量 GSIE**
   - 定义了以注视条件为核心的定量指标 **Gaze–Surface Intersection Error (GSIE)**：该指标利用注视射线与场景三维模型的交点所构成的位置误差；
   - 其关键作用是能够反映**位姿误差在任务场景中如何传播到最终的注视指向目标**，弥补传统 ATE、ARE 的不足。

## 六、主要实验结论与发现

- 传统位姿级指标（ATE/ARE）**明显不能反映**最终任务的完成质量。例如在具有旋转对称物体、或深度差距大的场景中，部分旋转误差可被平移量补偿，位姿均方误差大但GSIE反而低。
- 在所有场景中，**对象级椭球精化（MVEE）在GSIE指标上做到全面最优**，说明这类直接在对象空间施加刚体约束的优化手段，比单纯点的重投影在做机器人放置时更为有效。尤其体现在其并不总是产生最小ATE/ARE的趋势上。
- 参考选择方案中，Graph-based参考选择的SAcc在几乎所有情境下达到0.95⁻1.00，且有效将RE降到个位数像素级别，运行时间相对更低（约15 ms）。
- 在实际交互测试中，结合基于图选择+椭球精化的做法，物体选择准确率达到0.95⁻1.00，且放置成功率达到0.93⁻0.98，远优于基线，并在面对遮挡时明显胜过标记方式。

## 七、方法/实验设计的亮点

- **引入任务感知型对齐代价**：GSIE是一个跨设备变换算法在最终真实应用（放置位置）上的度量，这比单纯评价位姿误差更贴近应用，也暴露出之前文献缺失的任务层误差。
- **语义-空间组合的检索机制**：用语义类别与角度关系同时建立设备间关联，很好缓解了稀疏观测、惯常视差对跨设备对齐的限制，与传统哈希或外观检索的思路有明显对比；
- **对象级精化对局部不可靠像素的低依赖**：使用MVEE即摆脱了对逐点深度或质心匹配的过度信任，允许直接构造严密的椭圆体约束；
- 对评测一致性注意良好：统一特征匹配器/PnP、相同重建、相同场地，对无实际成功率的模型给出特殊说明；
- 实验场景组合兼顾合成型与真实场景、同时又覆盖不同物体几何（球形、盒形、任意），极大增强了结论的可靠性。

## 八、不足与局限

- **数据集规模与环境局限**：自建数据集是桌面静物与机器人单向观测的组合，虽有TUM补充，但均为室内受限场景，缺乏动态变化、光照差异或遮挡更为混乱的真实厨房/卧室互动等场景验证；
- **使用公开特征工具（YOLO、LightGlue、LSD）的稳定性依赖较强**：对于弱纹理、重复物体或极端视角，语义级分类识别可能不稳定，这也是SB场景中的线特征方法GSIE不够理想的重要因素；
- **算法时间结构未全面剖析**：虽然表中包含了组件的耗时，但在交互过程中未见关于缓存策略或与任务逻辑衔接的总综合延迟的分析，因此对实时交互中的端到端可用性仍未充分展示；
- **椭球法对非凸或不规则物体的误差特性缺乏深入讨论**：部分日常物体不一定适合用椭球体近似，会对对象级约束的收敛性形成局限；
- GIEs偏向放置在“可见范围表面”上，对目标点不在3D重建表面或视线折射面的情形，尚未考虑实际空间语义的关系。
- 多数TUM片段只有一个参考设备检索机制，但不否认对局部地面真值标记遮蔽可能部分帮助，导致对标记依赖度评估存在轻微偏乐观。
