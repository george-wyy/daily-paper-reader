## 摘要
由多模态大语言模型（MLLMs）驱动的移动GUI代理在人机智能方面展现出巨大潜力。然而，当前研究主要集中在被动任务执行上，缺乏对用户意图的全面“理解-预测-执行”过程，而这正是主动代理的核心需求。在本文中，我们提出了Act2Intention框架，通过整合理解、预测用户意图和执行决策来构建主动移动代理。首先，我们通过数据收集和验证生成构建了Act2Intention基准，包含52个应用中的72,511个意图和超过700,000个动作，从而为通过连续意图-动作轨迹评估主动代理建立了首个基准。我们进一步开发了Act2Intention代理，通过面向主动性的意图理解、个性化主动意图预测和经验引导的意图执行实现主动服务。实验结果表明，在相同代理框架下，基于Act2Intention基准进行监督微调，在意图理解、预测和执行方面分别比未微调的对应模型取得了+32.0 Acc-S、+10.25 Acc-S和+6.9 SSR分的绝对提升。这一成功凸显了Act2Intention基准的必要性和价值，它为开发和评估主动代理建立了标准化平台，从而为意图驱动的人机交互研究铺平了道路。

## Abstract
Mobile GUI Agents powered by multimodal large language models (MLLMs) show promise in human-computer intelligence. However, current research primarily focuses on reactive task execution while lacking a comprehensive understanding-prediction-execution process for user intentions, which are the core requirements of active agents. In this paper, we propose the Act2Intention framework that builds an active mobile agent by integrating understanding, predicting user intentions, and executing decisions. First, we construct the Act2Intention Bench through data collection and validated generation, comprising 72,511 intentions and over 700,000 actions across 52 apps, thereby establishing the first benchmark for evaluating proactive agents via continuous intention-action trajectories. We further develop the Act2Intention Agent, achieving proactive services through Proactive-oriented Intention Understanding, Personalized Proactive Intention Prediction, and Experience-guided Intention Execution. Experimental results show that supervised fine-tuning on Act2Intention Bench yields absolute improvements of +32.0 Acc-S, +10.25 Acc-S, and +6.9 SSR points over non-fine-tuned counterparts under the same agent framework for intention understanding, prediction, and execution, respectively. This success underscores the necessity and value of the Act2Intention Bench, which establishes a standardized platform for developing and evaluating proactive agents and consequently paves the way for research on intention-driven human-computer interaction.

### 1. 论文的核心问题与整体含义（研究动机与背景）
- **核心问题**：当前移动GUI代理（如AutoGLM、CogAgent、UI-TARS等）本质上属于**被动反应式执行者**，依赖用户显式指令（文本/语音）完成任务，缺少对用户意图的主动理解、预测与干预能力。在现实场景中，用户往往不愿显式描述意图，尤其是在需要前瞻性、自动化决策的场景下。
- **研究空白**：现有数据集（AITW、AndroidControl、AMEX、GUI-Odyssey等）聚焦离散的“指令–轨迹”任务，缺乏连续的多意图–动作轨迹，无法支撑“理解→预测→执行”的主动式代理研究。
- **论文目标**：提出**Act2Intention框架**，将主动移动代理范式定义为 **理解（Understanding）→ 预测（Prediction）→ 执行（Execution）** 三阶段，并构建首个支持该范式的基准数据集与Agent系统，完成从“被动响应”到“主动协助”的转变，推动意图驱动的人机交互研究。

### 2. 方法论
#### 2.1 核心思想
- 将主动代理拆分为三个可独立训练与评测的模块：
  - **意图理解**：从原始GUI原子动作序列中推断用户意图（含会话分割与语义描述）。
  - **意图预测**：基于历史意图序列、用户画像与当前时间，预测用户下一个可能的意图。
  - **意图执行**：基于用户确认的意图，结合历史经验轨迹与画像，在手机端逐步执行GUI操作。
- 框架以自然语言为中间表征，将异构的低层GUI动作统一转换为可推理的语义描述，再逐层完成高层的意图建模，实现从“动作”到“意图”再到“新动作”的闭环。

#### 2.2 关键技术细节
1. **Bench构建**：
   - 原始数据来自90名参与者的真实手机交互日志（2024/3/1–4/29），记录了时间戳、前台App、GUI观察、动作类型与参数（CLICK/LONG_CLICK/TYPE/SWIPE/PRESS），以及用户在应用切换时上报的意图描述。
   - **三子集设计**：RR（真实画像→真实轨迹）、RG（真实画像→合成轨迹）、GG（合成画像→合成轨迹），分别覆盖真实行为、扩充多样性与行为多样性扩展。
   - **合成数据生成**：使用Deepseek-R1实现Text-to-Persona与Persona-to-Persona（生成100个新画像）；迭代生成意图轨迹，约束时间/App/意图文本的连贯性；使用UI-TARS-1.5-7B在Android模拟器并行执行生成动作轨迹。
   - **双重质控**：
     - 意图滤波：用Deepseek-R1从合成意图序列重建画像，与原始画像计算余弦相似度，低于0.7即过滤（保留率92.63%）；
     - 动作滤波：基于意图、动作元数据、动作描述与最终截图，由Deepseek-R1判断轨迹是否达成目标（保留率87.03%）。
   - 最终规模：360个人像、72,511个意图、705,366个动作、52个App；包含约120个细粒度意图类别。
   - **数据划分**：测试集全部来自RR子集；OOD测试集为10位用户的随机数据，ID测试集为其余80位用户的最后20%数据；训练集为全部剩余数据（RR/RG/GG）。

2. **Act2Intention Agent**：
   - **动作描述**：使用VLM（如Qwen-VL-MAX）结合动作前后截图，生成标准化描述 `[On/In App], [Action], to [Purpose]`，存储在Memory模块。
   - **会话分割与意图理解**：用SFT微调LLM，以链式方式输出意图分组索引与各组的意图描述，完成 `分段→理解` 的联合任务。
   - **意图预测**：以历史50个意图 + 用户画像 + 当前时间为输入，输出预测意图及其类别；运行时在设备唤醒时展示建议，需用户确认。
   - **经验引导执行**：用all-MiniLM-L6-v2嵌入意图并检索相似轨迹，将相似历史轨迹与用户画像注入GUI Agent（如UI-TARS）的提示中，逐步执行并校验。

#### 2.3 任务形式化定义（文字表述）
- 意图理解：将动作描述序列分段为 m 个连续段，并为每段生成自然语言意图标签。
- 意图预测：由历史意图序列、当前时间与用户画像预测下一个意图。
- 意图执行：由用户确认的意图、历史动作轨迹、当前观察以及相似历史任务轨迹，迭代决策下一步动作，直到任务完成。

### 6. 主要结论与发现
- **SFT在Act2Intention Bench上显著有效**：在同一Agent框架下，微调模型在理解（+32.0 Acc-S）、预测（+10.25 Acc-S）、执行（+6.9 SSR）上均大幅优于未微调版本。
- **理解任务可学习性强**：微调后Acc-G可达96.65–100%，说明“分段–总结”式意图理解对SFT高度敏感；但Acc-S最高约0.50，说明边界正确不保证语义精确，存在“过度泛化/细节缺失”的粒度错配（D.1错误分析）。
- **预测任务**：微调后Llama-3.1-8B-SFT取得最高Acc-C（54.2%），超越所有闭源模型；Qwen-max为闭源最佳（48.5%）。无微调模型易产生语义合理但不符合预定义类别的开放型输出。
- **“先理解再预测”是有效分解**：移除理解模块后，GPT-4o与Qwen-2.5-7B-SFT的预测指标均大幅下降，证明高层意图抽象优于直接从原始动作序列预测。
- **经验引导执行有效**：加入相似历史轨迹后，UI-TARS-2B-SFT提升+9.9 SSR、UI-TARS-7B-SFT提升+3.2、GUI-R1-3B提升+6.8、CogAgent-9B提升+7.7，验证了跨Agent主干的可迁移性。
- **端到端仍有瓶颈**：最佳端到端SR仅22.7%（真实意图SR为47.6%），说明意图预测误差与长程执行误差共同构成主要限制；置信度回退可将推送案例的SR从22.7%提升至34.6%（阈值0.60）或34.6%（阈值0.80时推送到14%且SR达34.6%）。
- **OOD泛化有损**：微调模型在OOD下性能回落（如Llama-3.1-8B-SFT的Acc-G下降12.73），提示需更鲁棒的基座与持续适应。
- **数据合成互补**：RR/RG/GG数据共同训练最优（Acc-G=100.0、Acc-S=0.49），纯合成数据有助于分段但损伤语义精度。

### 7. 优点
- **问题定位精准**：针对“当前GUI代理只会被动执行”这一真实痛点，提出“理解→预测→执行”三阶段主动代理范式，具有前瞻性与普适性。
- **首个持续意图–动作基准**：Act2Intention Bench（72,511意图、70万+动作、52 App）填补了现有多模态GUI数据集在“连续多意图+行为画像+场景上下文”上的空白。
- **科学的数据生产与验证**：采用“真实采集 + 画像条件化生成 + 双重自动过滤（画像一致性+轨迹达成性）+ 人类真实性评估”的组合，有效兼顾规模、多样性与质量。
- **模块化、可组合的Agent架构**：理解/预测/执行三模块解耦，各模块可独立训练、评测、替换，便于社区复用与迭代。
- **实验严谨**：同时给出ID与OOD结果、多种VLM描述器消融、训练数据子集消融、画像消融、置信度回退消融与错误分析，并主动分析Acc-G与Acc-S之间的粒度gap，透明度高。

### 8. 不足与局限
- **数据覆盖与偏差**：仅90名匿名参与者（无人口统计信息：年龄、性别、地域、技术背景），可能反映特定用户群体；合成数据可能引入LLM的刻板模式，无法完全取代真实多样行为。
- **OOD泛化不足**：SFT模型在未知用户上的性能显著下降；未测试跨应用、全新UI布局或跨App长程意图。
- **用户中心评估缺失**：未验证真实用户对主动建议的“有用性、及时性、不打扰感”的主观感知；未做田野实验（in-situ study）。
- **介入时机（opportune moment）未建模**：当前只在设备唤醒或预定触发点显示建议，未将“何时主动打扰”作为学习任务。
- **执行评估偏保守**：SSR要求逐动作精确匹配，功能等价路径被判为失败；虽引入SR弥补，但SR在模拟器中评估，与真实设备性能可能有差异。
